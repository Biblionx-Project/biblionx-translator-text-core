###############################################################
# Notes on deploying the application
###############################################################

1. Application information:

   Translator-Core refers to the AI-based Portuguese-to-glosses (Libras) translation module.
   For the translator to work fully, make sure the translation API is configured and able to communicate with the core.
   This communication happens via async queues (AMQP), a request cache (Redis), and a SQL database (Postgres).
   The variables associated with these services must have matching values on both services.

   - Application name: {{ .Chart.Name }}
   - Version: {{ .Chart.Version }}
   - Release name: {{ .Release.Name }}
   - Namespace: {{ .Release.Namespace }}

2. How to access the application:
   {{- if eq $.Values.tradcore.service.type "LoadBalancer" }}
   - The application is exposed via LoadBalancer:
     (It may take a few minutes for the LoadBalancer IP to be provisioned. Use the following command to check the IP:
     kubectl get svc --namespace {{ .Release.Namespace }} -o wide)
  {{- else if eq .Values.tradcore.service.type "NodePort" }}
   - The application is exposed via NodePort:
     NodePort: {{ .Values.tradcore.service.nodePort }}
     Use the IP of any cluster node with the NodePort to access the application:
     URL: http://<Node-IP>:{{ .Values.tradcore.service.nodePort }}
   {{- else }}
   - The application is exposed via ClusterIP:
     URL: http://<Cluster-IP>:{{ .Values.tradcore.service.port }}
     (Only accessible from within the cluster)
   {{- end }}

3. Viewing logs:
   To view the API logs, run:
   kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

4. Scaling the application:
   To scale the application, run:
   kubectl scale deployment {{ include "tradcore.name" . }} --replicas=<desired-count> -n {{ .Release.Namespace }}

5. Troubleshooting:
   - If the application doesn't start, check the pod logs:
     kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
   - Check the service endpoints:
     kubectl get svc -n {{ .Release.Namespace }}

6. Uninstalling:
   To remove this release, run:
   helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
