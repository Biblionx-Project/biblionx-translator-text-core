###############################################################
# Notas sobre la implantación de la aplicación
###############################################################

1. Información de la Aplicación:

   El Translator-Core se refiere al módulo de traducción de portugués a glosas (Libras) basado en IA. 
   Para el pleno funcionamiento del traductor, asegúrese de que la API de traducción esté configurada y pueda comunicarse con el core.
   Esta comunicación se realiza a través de colas asíncronas (AMQP), caché de peticiones (Redis) y base de datos SQL (Postgres).
   Las variables asociadas a estos servicios deben tener los mismos valores para ambos servicios.

   - Nombre de la aplicación: {{ .Chart.Name }}
   - Versión: {{ .Chart.Version }}
   - Nombre de la release: {{ .Release.Name }}
   - Namespace: {{ .Release.Namespace }}

2. Cómo acceder a la aplicación:
   {{- if eq $.Values.tradcore.service.type "LoadBalancer" }}
   - La aplicación está expuesta a través de LoadBalancer:
     (Puede tomar algunos minutos para que se aprovisione la IP del LoadBalancer. Use el siguiente comando para verificar la IP:
     kubectl get svc --namespace {{ .Release.Namespace }} -o wide)
  {{- else if eq .Values.tradcore.service.type "NodePort" }}
   - La aplicación está expuesta a través de NodePort:
     NodePort: {{ .Values.tradcore.service.nodePort }}
     Use la IP de cualquier nodo del clúster con el NodePort para acceder a la aplicación:
     URL: http://<Node-IP>:{{ .Values.tradcore.service.nodePort }}
   {{- else }}
   - La aplicación está expuesta a través de ClusterIP:
     URL: http://<Cluster-IP>:{{ .Values.tradcore.service.port }}
     (Accesible solo desde dentro del clúster)
   {{- end }}

3. Visualizando logs:
   Para visualizar los logs de la API, ejecute:
   kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

4. Escalando la aplicación:
   Para escalar la aplicación, ejecute:
   kubectl scale deployment {{ include "tradcore.name" . }} --replicas=<cantidad-deseada> -n {{ .Release.Namespace }}

5. Resolución de problemas:
   - En caso de que la aplicación no inicie, verifique los logs de los pods:
     kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
   - Verifique los endpoints de los servicios:
     kubectl get svc -n {{ .Release.Namespace }}

6. Eliminación:
   Para eliminar esta release, ejecute:
   helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
